# Project Brief: Attenly

## Core Mission
Attenly is an AI-powered data extraction application that transforms unstructured documents (primarily PDFs) into structured, professional reports. The system serves insurance professionals, underwriters, and brokers who need to quickly extract and organize key information from complex documents.

## Primary Goals
1. **Automated Data Extraction**: Use AI to identify and extract specific data points from free-form text documents
2. **Template-Based Reporting**: Generate professional, formatted reports using predefined HTML templates
3. **Configurable Agents**: Allow users to create and customize extraction agents for different document types
4. **Streamlined Workflow**: Provide an intuitive interface for document upload, processing, and report generation

## Target Users
- **Insurance Underwriters**: Need to quickly analyze policy documents and create account summaries
- **Insurance Brokers**: Require loss history analysis and risk assessment reports
- **Risk Analysts**: Need structured data extraction from various insurance documents

## Core Value Proposition
Transform hours of manual document review and data entry into minutes of automated processing, while maintaining accuracy and professional presentation standards.

## Key Features
- **Agent System**: Configurable templates with specific data extraction questions
- **File Processing**: PDF upload and text extraction capabilities
- **Report Generation**: AI-driven data extraction with professional HTML output
- **User Management**: Secure authentication and session handling
- **Template Library**: Pre-built agents for common insurance document types

## Success Metrics
- Reduction in document processing time (target: 80% time savings)
- Accuracy of extracted data (target: 95%+ accuracy)
- User adoption and engagement
- Template library growth and usage

## Project Scope
**In Scope:**
- PDF document processing
- AI-powered data extraction
- HTML report generation
- User authentication
- Agent configuration system
- Template management

**Out of Scope (Current Phase):**
- Multi-format document support beyond PDF
- Advanced AI model training
- Enterprise integrations
- Mobile applications

## Technical Constraints
- Must handle sensitive insurance documents securely
- Reports must be print-ready and professional quality
- System must be responsive and handle multiple concurrent users
- Data extraction must be reliable and consistent

## Project Timeline
- **Phase 1**: Core infrastructure and basic agent system ✅
- **Phase 2**: Enhanced AI processing and template expansion (Current)
- **Phase 3**: Advanced features and enterprise capabilities (Future)
