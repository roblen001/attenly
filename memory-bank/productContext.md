# Product Context: Attenly

## Why This Project Exists

### The Problem
Insurance professionals spend countless hours manually reviewing documents, extracting key data points, and creating structured reports. This process is:
- **Time-consuming**: Manual review can take hours per document
- **Error-prone**: Human fatigue leads to missed or incorrect data extraction
- **Inconsistent**: Different reviewers may extract different information from the same document
- **Costly**: High-skilled professionals spending time on repetitive tasks

### The Opportunity
With advances in AI and document processing, there's an opportunity to automate this workflow while maintaining the quality and accuracy that insurance professionals require.

## How It Should Work

### User Journey
1. **Agent Selection**: User chooses or creates an agent template for their document type
2. **Document Upload**: User uploads PDF documents for processing
3. **AI Processing**: System extracts data using the agent's configuration
4. **Report Generation**: Professional HTML report is generated with extracted data
5. **Review & Export**: User can preview, edit, and export the final report

### Core Workflows

#### Document Processing Workflow
```
Upload PDF → Extract Text → AI Analysis → Data Extraction → Template Population → Report Generation
```

#### Agent Configuration Workflow
```
Define Template → Set Questions → Configure Placeholders → Test & Validate → Deploy
```

#### User Management Workflow
```
Registration → Authentication → Dashboard Access → Agent Selection → Document Processing
```

## User Experience Goals

### Primary Experience Principles
1. **Simplicity**: Complex AI processing hidden behind intuitive interface
2. **Speed**: From upload to report in under 5 minutes
3. **Accuracy**: AI extraction with human review capabilities
4. **Professional Output**: Reports ready for client presentation
5. **Flexibility**: Customizable templates for different use cases

### Key User Interactions
- **Drag & Drop Upload**: Intuitive file handling
- **Progress Indicators**: Clear feedback during processing
- **Preview & Edit**: Ability to review and modify extracted data
- **One-Click Export**: Instant PDF generation for sharing

### Success Scenarios
1. **Underwriter**: Uploads policy documents, generates Executive Comppany Summary in 3 minutes
2. **Broker**: Processes loss history documents, creates client-ready report
3. **Risk Analyst**: Batch processes multiple documents with consistent formatting
